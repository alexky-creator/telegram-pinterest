# Privacy Policy

Last updated: January 2026

## Overview
This application enables users to transfer content from Telegram to Pinterest using secure OAuth 2.0 authentication.

## Data We Collect
- Pinterest OAuth tokens (access tokens only, passwords never stored)
- Board IDs you authorize
- Telegram channel information you provide
- Pin metadata (titles, descriptions, links)
- Technical logs (for debugging)

## How We Use Data
- To enable content transfer between platforms
- To improve reliability
- To comply with Pinterest/Telegram Terms of Service
- For security purposes

## Data We DON'T Share or Sell
- We never sell data to third parties
- We never use data for marketing without consent
- We never share with unauthorized parties

## Your Rights
- You can revoke access anytime (via Pinterest settings)
- You can request data deletion
- Contact us

## Security
All data transmitted via HTTPS. OAuth 2.0 used for authentication.

## Third Parties
- Pinterest: https://pinterest.com/about/privacy/
- Telegram: https://telegram.org/privacy
